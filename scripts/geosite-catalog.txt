# scripts/geosite-catalog.txt — geosite tags to bundle into the deploy tarball.
#
# stage.sh fetches every line below + every URL in gateway.yaml, downloads the
# corresponding .srs from sagernet/sing-geosite, and ships them under
# /etc/leap/singbox/rule-sets/. The management API surfaces this list as
# `available` in GET /api/geosites; operators pick a subset to enable via
# PUT /api/whitelist.
#
# Lines starting with # and blank lines are ignored. One tag per line, no
# .srs suffix. Format: geosite-<name>.
#
# Add or remove freely — re-run scripts/stage.sh to refresh the bundle.
# Re-deploy (install.sh) to push the new catalog to the node.
#
