# scripts/rule-set-catalog.txt — rule-set tags to bundle into the deploy tarball.
#
# stage.sh fetches every line below + every URL in gateway.yaml, downloads the
# corresponding .srs from the appropriate sagernet repo (decided by prefix),
# and ships them under /etc/leap/singbox/rule-sets/. The management API
# surfaces these as `available` in GET /api/rule-sets; operators pick a subset
# to enable via PUT /api/whitelist.
#
# Format:
#   - Lines starting with # and blank lines are ignored.
#   - One tag per line, no .srs suffix.
#   - Prefix decides upstream:
#       geosite-*  →  sing-geosite repo (domain match)
#       geoip-*    →  sing-geoip repo   (IP CIDR match)
#
# When to add a geoip-* entry (the field is dangerous if abused):
#   ✓ App hardcodes IPs and skips DNS — Telegram MTProto, Signal, ProtonVPN
#     bootstrap, certain game servers, etc.
#   ✗ Mainstream HTTPS apps that resolve via DNS — geosite-* already catches
#     them via fakeip + sniff. Adding geoip-cloudflare / geoip-google routes
#     half the internet through the airport and defeats whitelist mode.
#
# Add or remove freely — re-run scripts/stage.sh to refresh the bundle.
# Re-deploy (install.sh / make deploy-full) to push the new catalog to nodes.
